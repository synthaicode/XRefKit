# XDDP Change Design Entry

This Skill produces a change design from sourced current specification evidence.

The output must preserve:

- traceability from current specification evidence to the proposed change
- visible unknowns where current specification evidence is missing
- assumptions separated from known facts
- used XIDs for all evidence used as judgment basis

Do not infer the current specification without a loaded source.
Do not omit traceability or unknowns.
