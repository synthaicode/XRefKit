# Brownfield reporting and closure

Separate overview from detailed evidence. The overview states objective,
policy, scope, impacts, result classification, residual risk, and required
decisions. Detail contains structure, change/impact map, data investigation,
test mapping, pre/post results, logs, and unresolved paths.

Every phase begins with `Status`, `Result`, `Evidence`, `Open Items`, and
`Handoff`. Before closure, trace upstream items, attach evidence and
Knowledge/pattern basis, give every unknown a reason, impact, next action, and
owner, and record the next-phase input package.
