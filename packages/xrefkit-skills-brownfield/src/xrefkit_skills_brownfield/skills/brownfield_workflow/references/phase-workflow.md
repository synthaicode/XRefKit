# Brownfield phase workflow

Use `requirements -> planning -> design -> manufacturing -> testing`. Carry
forward upstream references, decisions, unknowns, evidence, owners, gates, and
handoff conditions. Planning defines tools, data, environment, risks, and
release/rollback policy; testing executes the approved plan.
