# Pattern decision report

Produce an overview and detailed evidence for each enhancement pattern
decision. Explain the selected pattern, rejected alternatives, complexity and
operational impact, data-lifecycle impact, tests, evidence, open decisions,
and approval owner.

Detailed evidence includes representative peers, before/after structure and
data flow, option comparison, new states/configuration/jobs/monitoring/support
steps, deployment/rollback/recovery impact, lifecycle and downstream
propagation, and XDDP links from `xddp_row_id` to pattern, work, test, evidence,
and decision IDs. Unknowns require reason, impact, resolver, and owner.

End with the plain-language decision, protected invariants, permitted change,
remaining risks, human approvals, and next handoff.
