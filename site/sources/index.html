Controlled AI Work With XRefKit

AI work needs a goal,
bounded responsibility, and proof.

XRefKit is an operating base for controlled AI work. A Goal defines the desired state, routing selects the next Skill, and the workflow protocol prevents incomplete work from being treated as complete.

Goal + acceptance
→
Semantic routing
↓
Skill + selected Knowledge
→
Workflow protocol
↓
Human acceptance / handoff

XRefKit turns ad hoc AI usage into resumable, reviewable work with explicit evidence.
