AI can finish a local task, but it does not automatically preserve business completion, decision ownership, or the state required by the next responsibility.

XRefKit is an operating base that connects AI work from a Goal to human acceptance with verifiable progression. Managed Skills, Knowledge, and execution contracts can be distributed to multiple users through MCP.

Judgment Replication

Organizations scale by replicating judgment, not processing capacity alone. XRefKit distributes that judgment as stable, versioned reference.

Get started

Python 3.11 or later is required. Install XRefKit, then initialize it in your target workspace.

1. Install
python -m pip install xrefkit
2. Initialize your workspace
xrefkit init
xrefkit --help
3. Connect an AI client if needed

MCP is optional. Follow the repository's setup guide for your client and review the generated configuration before applying it.
