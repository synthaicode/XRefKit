Get started

Python 3.11 or later is required. Install XRefKit, then initialize it in your target workspace.

1. Install
python -m pip install xrefkit
2. Initialize your workspace
xrefkit init
xrefkit --help
3. Connect an AI client if needed

MCP is optional. Follow the repository's setup guide for your client and review the generated configuration before applying it.
