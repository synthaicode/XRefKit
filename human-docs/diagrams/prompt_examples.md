# 利用者 AI 向けプロンプト例

このフォルダの図は、図だけでなく対応する `.md` と組み合わせて使います。

## 例

- この図を初心者向けに説明して
- この図から XRefKit の責務分離だけ説明して
- この図を使って Business Pack の概念を管理者向けに説明して
- この図と関連図の関係を整理して
- この図にある Operational Memory と Dashboard の関係だけ説明して
- この図を使って、なぜ人間が方向性を示し、具体修正は AI が行うのかを説明して

## 使い方の注意

- 用語定義は図の `.md` にある固定定義を優先する
- 詳細化するときも、図の非対象を崩さない
- `docs/` の AI 正本と混同しない
