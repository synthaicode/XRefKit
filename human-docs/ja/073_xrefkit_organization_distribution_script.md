# XRefKit 組織配布シナリオ

<a id="xid-D7A3C9E51B84"></a>

この資料は、XRefKit で管理・検証した知識と手順を、組織の AI 利用環境へどう届けるかを説明する。正本の作り方や実行内容の改善は扱わず、管理済み資産を同じ契約で利用可能にするところを範囲とする。

## ゴール

- 視聴者が、管理と配布を別の責務として理解する。
- 視聴者が、配布単位には文書だけでなく、起動・進行契約、責務定義、必須知識、実行ツールが含まれることを理解する。
- 視聴者が、世代単位の公開と `current.json` の役割を理解する。
- 視聴者が、リポジトリ、導入済みパッケージ、MCP のどこからでも同じ XID を解決できることを理解する。
- 視聴者が、MCP は配布と参照解決を担い、作業実行はクライアント側が担う境界を理解する。

## 前提

「XRefKit リポジトリ概要」で、知識、手順、実行記録、証拠が更新・検証可能な正本として管理されていること。

## 構造

1. 管理済み資産を組織へ届ける
2. 配布する契約と資産を定める
3. Python パッケージとして版を揃える
4. 世代単位で原子的に公開する
5. 利用環境に応じた参照元から XID を解決する
6. MCP を薄い配布境界として使う
7. クライアント側で整合性と信頼を確認する
8. 一つの正本を同じ契約で複数環境へ届ける

## 範囲外

- 組織固有知識や責務定義の作成方法
- 作業進行規約による実行管理
- XID 利用ログを使った知識・手順の改善

これらは「XRefKit リポジトリ概要」で説明する。
