相関

Skill Run と MCP の記録を、同じ run_id で突き合わせる

client 側: Skill Run log

  • skill_id と run_id
  • selected / loaded / applied XID
  • artifact、judgment、handoff

MCP 側: audit log

  • run.bound と xid.resolved
  • mcp_session_id
  • repository_fingerprint と content hash
同じ run_id がなければ、サーバーの解決記録と作業結果を確実には結べない。
